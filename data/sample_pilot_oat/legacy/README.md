# Sample Pilot Dataset — Avena (Oat) Field, Zacatecas, México

## Overview

This dataset is a **reproducible snapshot** of a real precision-agriculture analysis
executed on 4 May 2026 by the AgRegen 5.0 platform (https://ag-regen.com) on a
12.73 ha irrigated oat field in Ejido Miguel Auza, Zacatecas, México.

It is provided as supplementary material for the SoftwareX article:

> *AgRegen 5.0: A Spanish-language platform for regenerative precision agriculture
> integrating satellite remote sensing, geostatistical interpolation, and AI-assisted
> variable-rate prescription.*

## Prescription Logic

Zones are ordered from lowest to highest NDVI. The variable-rate prescription
follows an inverse-linear rule: lower NDVI indicates nitrogen deficiency and
receives a higher correction dose. The dose boundaries (20–80 kg/ha) and rationale
per zone were generated by GPT-4o with the NDVI context and an optimal range of
[0.40, 0.60] for oat at harvest stage.

## Data Provenance

This dataset is a direct, unmodified export from the AgRegen 5.0 production
PostgreSQL database. No values were synthesised, rounded beyond storage precision,
or recalculated. See `provenance.json` for full traceability including original
database record IDs and SQL queries used.

## Independence from External Services

All files in this directory are static. Running the demo and tests requires
**no external API calls, no internet connection, and no database access**.
